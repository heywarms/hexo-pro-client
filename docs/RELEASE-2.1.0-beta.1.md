# Hexo Pro 2.1.0 Beta 1

发布日期：2026-10-15。本次为测试版本，升级前请备份博客源文件。

## 更新内容

- 重新整理工作台、文章列表及编辑器，统一分类、图片、回收站、配置、部署、同步、主题和设置页面。
- 工作台展示最近草稿、最近编辑、待办及文章趋势，完善空白、错误、深色模式和窄屏显示。
- 编辑器支持直接粘贴图片、读取新上传的本地图片、调整图片宽度，并在 Markdown 与正文预览中保留尺寸。
- 改进文章属性面板、Front Matter 编辑及发布操作，保留原稿中的未知属性。
- 博客链接支持当前本地预览地址或自定义地址，并尊重关闭链接转换的设置。
- 包含 Beta 0 的块编辑器、文档永久标识、GitHub 双向同步、Android / iOS 离线写作、备份及桌面运行时更新。

## 下载

各端安装包、插件压缩包、校验文件及实际验证范围，以 [GitHub 预发布页面](https://github.com/heywarms/hexo-pro/releases/tag/v2.1.0-beta.1) 为准。

插件压缩包可在 Hexo 博客目录安装：

```sh
npm install --save ./hexo-pro-2.1.0-beta.1.tgz
```

插件需要 Node.js 20.19.0 或更新版本。手机安装、GitHub 连接与备份方法见 [手机 App 指南](MOBILE_APP.md)。iOS 模拟器包不能安装到 iPhone，真机分发需要相应的 Apple 签名。
