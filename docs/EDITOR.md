# 博客编辑器

文章和页面共用 `client/src/components/BlogEditor`。默认使用 BlockNote 块编辑器，Markdown 源码模式使用 CodeMirror 6，保存格式仍是 Hexo 的 Markdown 文件和 Front Matter。

## 写作

- 输入 `/` 插入标题、列表、检查清单、引用、代码、图片、表格和分隔线。
- 选中文字可设置粗体、斜体、删除线、行内代码或链接。
- 拖动块左侧手柄调整顺序，手柄菜单也可上移、下移或删除。
- 图片沿用已有图片存储设置，默认上传至本地博客。本地图片通过受认证的原图接口预览，粘贴后即可显示，无需先生成或部署；Markdown 仍保存博客图片路径。
- 鼠标移到图片上后，拖动左右两侧手柄可等比例调整大小；图片块菜单也提供 25%、50%、100% 正文宽度。尺寸随正文自动保存，重新打开和主题预览均保留。调整过尺寸的图片使用标准 `<img src="…" alt="…" width="…">` 保存，未调整的图片仍使用 Markdown 图片语法。
- 编辑内容和标题会自动保存，顶部显示保存状态；失败时可重试。标题查重、改名和正文使用同一保存队列；发布、撤回或返回列表前等待待保存内容写入。
- 尚未保存成功的修改会先写入浏览器 IndexedDB 恢复副本。重新打开同一文章可查看、导出或恢复；每个编辑会话分别保存，其他标签页成功保存不会删除本会话的副本。浏览器存储不可用时会明确报错，应导出当前内容。
- 文章和页面读取返回 `revision`，编辑器保存携带 `baseRevision`；服务器版本已变化时返回 409，不覆盖其他设备或 MCP 的修改。可比较服务器与本地全文后明确选择保存，或返回编辑合并。旧客户端未传版本时仍兼容，但不具备版本冲突检测。
- 工具栏可随时切换 Markdown 源码；设置页可以选择默认编辑模式。
- 标题与正文位于同一写作区域，点击标题旁的编辑按钮修改，按 Enter 保存、Escape 取消；删除操作位于顶部「更多文章操作」菜单。

块编辑只提供可保存为 Markdown 的内容。打开已有文章前会比较导入和导出的 Markdown 结构；HTML、Hexo 标签、公式、脚注等无法完整保留的内容自动使用源码模式。自动切换只影响当前文章，不改变默认偏好，也不会因打开文章而重写文件。

## 当前主题预览

点击「主题预览」后，可并排写作或放大预览。内容变化会自动刷新，也可手动刷新以加载刚切换的主题。

`POST /hexopro/api/preview/:kind/:id` 复用本地 Hexo 实例，依次执行文章渲染、标签与过滤器、主题模板和注入器。它使用正在编辑的内容和标题，保留已保存的文章元数据；支持草稿和页面，不会发布草稿、写入预览内容或生成博客文件。主题资源按本地博客地址加载，预览 iframe 与管理界面隔离。

该功能不需要新增云服务器。真实主题预览需要现有的本地 Hexo 服务运行；移动端尚未在这次修改中实现。

## 开发验证

```sh
yarn test:editor
npx tsc --noEmit
yarn build
node hexo-pro-desktop/scripts/copy-hexo-pro.js
```

编辑器测试覆盖 Markdown 兼容性、保存合并与失败重试、文章地址稳定性，以及真实 Hexo 主题渲染和热切换。桌面端复制脚本会自动包含根目录运行时模块，包括 `preview_api.js`、`auth_security.js` 与 `document_write.js`。文档写锁在单个服务进程内生效，文件与身份索引使用失败回滚，但不提供跨进程或断电级事务。
